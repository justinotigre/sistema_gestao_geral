# SE TELECOM — Apresentação para GitHub Pages

Este pacote é uma **demonstração estática** do Sistema de Gestão de Especialidade. Foi preparado para publicação gratuita no GitHub Pages.

## O que contém
- Interface responsiva com navegação lateral.
- Dashboard com indicadores e gráfico ilustrativos.
- Páginas de demonstração para Especialistas, Equipamentos, Utilizadores, Feed, Comunicados, Oportunidades, Relatórios e Configurações.
- Pesquisa simples, filtros de exemplo e alternância de tema claro/escuro.
- Identidade SE TELECOM e imagens de insígnias incluídas no projecto original.

## Importante
- Os dados, nomes, números e publicações exibidos são fictícios.
- Não existe autenticação real, PHP, MySQL, gravação de registos, upload de ficheiros ou envio de candidaturas.
- Botões de criação/exportação mostram avisos demonstrativos em vez de gravarem dados.
- Esta versão é exclusivamente para apresentação. Não substitui a aplicação completa V4.53.
- Não inclua credenciais, dados pessoais, ficheiros de utilizadores ou cópias da base de dados neste repositório público.

## Publicar no GitHub Pages
1. Extraia o ZIP para uma pasta no computador.
2. Entre em https://github.com e crie um repositório novo, por exemplo `sge-telecom-apresentacao`.
3. Selecione a opção **Public** para permitir acesso público à apresentação. Não envie dados confidenciais.
4. Envie os ficheiros e pastas desta pasta para a raiz do repositório. Confirme que `index.html` fica na raiz, e não dentro de outra subpasta.
5. No repositório, abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Escolha a branch `main` e a pasta `/(root)` e clique em **Save**.
8. Aguarde a publicação e abra o endereço indicado na secção Pages (normalmente `https://SEU-UTILIZADOR.github.io/sge-telecom-apresentacao/`).

## Teste local
Abra `index.html` num navegador moderno. A interface é estática e não requer instalação.
